## 👋 Sobre mim

Sou **desenvolvedor fullstack** e gosto de ver um sistema inteiro funcionando, do banco de dados à tela. Meu forte é **backend em C#/.NET**, e no front trabalho com **Angular, React e TypeScript**. Também cuido da parte que costuma ficar esquecida: contêineres, deploy e monitoramento.

Hoje o meu dia a dia é construir plataformas web para uso real: sistemas de ensino, ferramentas de gestão interna e sites institucionais. Fora do trabalho, uso projetos pessoais para testar ideias, como o meu portfólio, que é um **skatepark 3D explorável**.

- 🔧 **Backend:** APIs REST em C#/.NET e Node.js, com PostgreSQL
- 🎨 **Frontend:** Angular, React/TanStack e TypeScript, com foco em acessibilidade e responsividade
- ☁️ **Infra:** Docker, Cloudflare, Render, Azure e AWS, além de observabilidade com Datadog e Kibana
- 🧪 **Explorando agora:** WebGL/Three.js, integração com IA (Gemini) e automação de WhatsApp
